# Supebuff Extensions

This branch is maintained by the trusted dev CI. It contains verified signed Release APKs, launcher icons and the AniZen-compatible catalogue.

Use the [Automatic installation button in the source README](https://github.com/Supebuff/sb-extensions-source/blob/dev/README.md#option-1-automatic), or add `https://raw.githubusercontent.com/Supebuff/sb-extensions-source/repo/index.min.json` in AniZen.

Source code and publishing instructions: [dev branch](https://github.com/Supebuff/sb-extensions-source/tree/dev).
